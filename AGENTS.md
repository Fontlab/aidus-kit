# Working on this kit

Read README.md, prompts/AIDUS.md and the Python agent guide before writing FontLab scripts. Use installed tool schemas as capability evidence. Do not execute font mutations or publish this repository merely because the kit contains examples.

Generated references are snapshots: refresh them through tools/sync_references.py from an authorized source checkout. Keep authored examples read-only unless a new editing example is explicitly scoped, labelled, and tested on disposable data.

Run tools/verify.py and the unittest suite after changes. No credentials, personal paths, font files or application binaries belong in the release. Preserve the MIT license and copyright notice when modifying or redistributing the kit.
